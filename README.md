# 固定點架設｜SREDDA・分力與均力・夾角與偏離受力

Reveal.js 互動簡報，沿用「台灣山難事故及高風險環境發生案例與救援方法」研討會簡報的做法（純中文版）：18 頁內容＋文字雲＋投票＋結尾，全場建議 17 分 40 秒。

- **線上網址**：https://phu00572.github.io/anchor-building/
- **章節**：引起動機（封面、文字雲、北絲鬮溪案例）→ 維持注意（SREDDA、分力均力、夾角受力）→ 喚起行動（甜蜜點、偏離點／COD 強度值、現場檢核）

## 聽眾互動（Firebase，SLUG `anchor2026`）

- **封面 QR code**：手機掃描直接進入文字雲頁；投票頁另有 QR code 直達投票。
- **文字雲**：「架設固定點時，你第一個檢查什麼？」
- **投票「先猜再看」**：兩點分力夾角多少最理想？講者按「揭曉答案」標出正解（C　45°～60°）。
- **匿名提問牆**：每一頁左側都可以拉開，可互相按讚。
- **課後清空資料**：網址加 `?reset=1`（https://phu00572.github.io/anchor-building/?reset=1），確認後清空文字雲、投票與提問牆。

## 頁面互動

案例卡、SREDDA 卡、架設方式卡可點擊展開；對照表可點選列標示；角度實驗室可拖拉夾角與偏離角；最後一頁是可勾選的現場檢核清單。偏離點（COD）頁點選任一列，右邊示意圖會跟著改變夾角與受力。
